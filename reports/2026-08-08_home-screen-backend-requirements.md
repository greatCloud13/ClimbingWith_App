# 백엔드 요청사항 보고서

- **작성일**: 2026-08-08
- **작성자**: Claude (앱 개발)
- **배경**: 홈 화면(즐겨찾기 클라이밍장 카드, 주요 공지 슬라이드) 구현 중 확인된 필요 API 및 기존에 보고했던 버그의 재정리

## 1. 신규 API 요청

### 1-1. 즐겨찾기 클라이밍장 목록
- **용도**: 홈 화면 상단 "즐겨찾기 클라이밍장" 가로 카드 슬라이드
- **요청 스펙(제안)**: `GET /api/gyms/favorites` → `[{gymId, name, area, ...}]` (로그인 사용자 기준)
- **현재 상태**: API 부재로 클라이언트에 목업 데이터 3건으로 임시 구현함 ([home_mock_data.dart](../lib/features/home/data/home_mock_data.dart))
- **우선순위**: 높음 (홈 화면 핵심 기능)

### 1-2. 주요 공지 목록
- **용도**: 홈 화면 "주요 공지" 자동 회전 슬라이드, 탭하면 상세로 이동
- **요청 스펙(제안)**: `GET /api/notices` → `[{id, title, subtitle, body, ...}]`
- **현재 상태**: API 부재로 목업 데이터 3건으로 임시 구현함
- **우선순위**: 높음

### 1-3. 알림
- **용도**: 홈 화면 우측 상단 알림 버튼 (읽지 않은 알림 수, 목록)
- **현재 상태**: 버튼만 배치, 탭하면 "준비 중" 안내만 표시 (API/화면 모두 미구현)
- **우선순위**: 중간

### 1-4. 완등 스트릭 / 연속 방문일
- **용도**: 홈 화면 로그인 사용자용 "N일 연속 방문 중 · 이번달 완등 N회" 카드
- **요청 스펙(제안)**: `GET /api/records/streak` → `{consecutiveDays, monthlyClimbCount, ...}`
- **현재 상태**: API 부재로 목업 값(5일, 12회)으로 임시 구현함
- **우선순위**: 중간

### 1-5. 친구 활동 피드
- **용도**: 홈 화면 "친구 활동" 가로 카드 (친구가 어디서 무엇을 완등했는지)
- **요청 스펙(제안)**: `GET /api/friends/activities` → `[{friendNickname, gymName, grade, createdAt, ...}]`. 친구/팔로우 개념 자체가 백엔드에 있는지 먼저 확인 필요
- **현재 상태**: API 부재로 목업 데이터 3건으로 임시 구현함
- **우선순위**: 중간 (친구 관계 API가 선행되어야 함)

## 2. 기존 버그 (2026-08-08 CORS 확인 시 함께 발견, 재보고)

### 2-1. 회원가입 유효성 검증 미작동
- `POST /api/auth/signup`에 DTO 제약(아이디 4~20자, 이메일 형식, 비밀번호 8~20자)을 위반하는 값을 보내도 200으로 가입이 성공함
- 확인에 사용한 값: `username: "a"`, `nickname: "a"`, `email: "not-an-email"`, `password: "123"` → 실제로 계정이 생성됨
- 추정 원인: 컨트롤러 파라미터에 `@Valid` 누락, 또는 예외 핸들러가 `MethodArgumentNotValidException`을 처리하지 않음
- **확인 후 조치 필요**: 테스트로 생성된 `username: "a"` 계정 정리

### 2-2. 로그인 실패 시 500 반환
- 존재하지 않거나 틀린 비밀번호로 `POST /api/auth/login` 호출 시 401이 아닌 500 `SERVER_ERROR`가 내려옴
- 추정 원인: 인증 실패 케이스가 예외 처리 없이 그대로 상위로 전파됨

## 3. 참고 — 확정된 사양

- 에러 응답 포맷: `{success: false, data: null, error: {code, message}}` (실제 호출로 확인)
- 성공 응답은 래핑 없이 flat (예: 로그인 성공 시 `{token, username, role, nickname, managedGymId}`)
